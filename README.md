# 学海无涯

文献精读报告站。每篇论文按七个维度拆开写：**概述、原文引用、原理总结、可借鉴之处、相关理论知识、通用词汇、专业词汇**。

原先是「集大成者」总台里的一个模块，现已独立成站 —— 与雾里楼台、汉语、现代材料、量子统计、经济专题平级，各自一个域名路径、各自维护。

线上：<https://kinghihido.github.io/paper-reading/>

## 页面

| 文件 | 作用 |
| --- | --- |
| `index.html` | 文献列表。方向筛选、关键词搜索、三个统计数字、可折叠的词汇表 |
| `report.html?id=<学号>` | 单篇阅读报告，七个维度全文 + 该篇词汇表 |

## 数据怎么存的

先说清楚：**这里是纯静态站点，没有后端，没有构建步骤**。数据分三层：

| 层 | 文件 | 大小 | 加载时机 |
| --- | --- | --- | --- |
| 索引 | `papers-index.json` | 15 KB | 列表页首屏，每次刷新都取 |
| 单篇正文 | `reports/<id>.json` | 约 20 KB / 篇 | 点进详情页才取 |
| 词汇总表 | `vocab.json` | 86 KB | 展开词汇面板才取 |

首屏只下 15 KB。**以前在总台里是一份 406 KB 的 `papers.json` 一次全量下载**，22 篇时还能忍，再多就会拖慢；拆成站正好顺手分页了。

浏览器本地存的键：

- `lit.index` —— 索引副本，兜离线和秒开
- `lit.vocab` —— 词汇表副本
- `lit.migrated` —— 迁移标记

### 从旧总台迁过来会不会丢东西

不会。两个站都在 `kinghihido.github.io` 下，**同源**，localStorage 互通。首次进入本站会跑一次 `migrateFromLegacy()`：把旧键 `jdc.papers` 里已有的记录降级成索引格式存到 `lit.index`，并顺手把 `jdc.vocab` 搬到 `lit.vocab`，之后不再重复。

旧键不清空 —— 万一以后给它绑了独立域名，那份全量正文还能当详情页的兜底来源用。

## 加一篇文献

三步：

1. 照 `reports/raman-001.json` 的字段写一份新的，文件名就是 `id`（小写、连字符，如 `raman-014`）；
2. 往 `papers-index.json` 里加一条 —— `id / title / meta / status / createdAt / updatedAt / summary`，其中 `summary` 截断到 180 字即可，列表页只用到这里；
3. 词汇不重复的会自动进 `vocab.json`，有的话把新词条按 `{term, english, definition, category}` 补进去；不想手动就用 `skills/paper-reader/` 里的技能交给 AI 生成。

`id` 的前缀决定列表页的方向标签：`raman-*` → Raman，`tmd-*` → TMD 生长。

## 视觉

沿用「一套视觉」：纸色底、宋体标题、发丝线分格。样式全在 `assets/style.css` 一个文件里，**页面里不写 `<style>`，也不定义私有调色板** —— 这是上一轮从总台继承下来的规矩，别破。

配色变量集中在 `:root`：

| 变量 | 值 | 用在哪 |
| --- | --- | --- |
| `--paper` | `#ebeef0` | 页面底色（略偏冷的纸，压住苍蓝） |
| `--ink` | `#131a1e` | 正文强调 |
| `--ink-1` | `#1b2226` | 标题（补齐了这个变量，报告页标题色才真正生效） |
| `--ink-3` | `#5b6367` | 次要信息，对比度约 5.3:1，过 WCAG AA |
| `--accent` | `#2f5d7c` | 苍蓝主色，对比度约 6:1 |
